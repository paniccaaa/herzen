### Теоретическая часть анализа

#### Корреляционный анализ
Корреляционный анализ помогает выяснить степень линейной зависимости между переменными. Это ключевой инструмент для определения взаимосвязей между характеристиками, такими как площадь или количество единиц, и ценой продажи апартаментов.

Коэффициент корреляции Пирсона (\(r\)) варьируется от -1 до 1:
- **\(r = 1\)**: идеальная положительная линейная зависимость (если одна переменная увеличивается, другая также увеличивается).
- **\(r = -1\)**: идеальная отрицательная линейная зависимость (если одна переменная увеличивается, другая уменьшается).
- **\(r = 0\)**: отсутствие линейной зависимости.

#### Формула Пирсона для корреляции:
Формула для вычисления коэффициента корреляции \(r\) между переменными \(X\) и \(Y\):

\[
r = \frac{\sum (X_i - \bar{X})(Y_i - \bar{Y})}{\sqrt{\sum (X_i - \bar{X})^2} \cdot \sqrt{\sum (Y_i - \bar{Y})^2}}
\]

где:
- \(X_i\) и \(Y_i\) — значения переменных;
- \(\bar{X}\) и \(\bar{Y}\) — средние значения;
- \(\sum\) — суммирование по всем наблюдениям.

Теперь обсудим интерпретацию результатов, чтобы понять, насколько значимы факторы для цены:

3. **RESIDENTIAL UNITS и SALE PRICE**:
