#### 1. **Запуск контейнеров с помощью Docker Compose**

Для начала работы с проектом необходимо поднять контейнеры с помощью Docker Compose. Для этого выполните следующую команду:

```sh
docker-compose up -d
```

- **`docker-compose up -d`**: Эта команда запускает все контейнеры, определённые в файле `docker-compose.yml`, в фоновом режиме. Убедитесь, что у вас правильно настроены образы для PostgreSQL, а также другие необходимые сервисы.
- После выполнения этой команды контейнеры будут запущены, и вы сможете начать работу с базой данных и приложением.

#### 2. **Проверка состояния контейнеров**

Для проверки того, что контейнеры запущены и работают корректно, используйте команду:

```sh
docker ps
```

#### 3. **Применение миграций базы данных**

Для того чтобы обновить схему базы данных в соответствии с моделями, выполните миграции. В рамках проекта миграции выполняются через Flask-Migrate с использованием Alembic.

##### 3.1. **Создание миграций**

Перейдите в директорию проекта и выполните следующую команду для создания миграции:

```sh
flask db migrate -m "Initial migration"
```

- Команда создаёт новый файл миграции на основе изменений в моделях базы данных. Например, если вы добавили или изменили таблицы, миграции будут отражать эти изменения.
- В данном случае создается миграция для создания таблиц `users` и `transactions`.

##### 3.2. **Применение миграций**

После того как миграция создана, нужно применить её к базе данных:

```sh
flask db upgrade
```

- Команда применяет миграцию к базе данных, создавая или изменяя таблицы в соответствии с описанием миграции.
- Убедитесь, что миграция прошла успешно, проверив таблицы в базе данных.

#### 4. **Запуск приложения**

Теперь, когда контейнеры подняты и миграции применены, можно запустить приложение.

Для запуска Flask-приложения используйте команду:

```sh
flask run
```

- Это запустит сервер Flask на локальном хосте (по умолчанию `http://127.0.0.1:5000`).
- Вы можете открыть этот адрес в браузере или использовать инструменты для тестирования API (например, Postman), чтобы взаимодействовать с REST API.

#### 5. **Проверка работы**

1. Для проверки работы API вы можете отправить запросы на один из эндпоинтов, например:
   - **POST `/auth/login`** — для получения JWT токена.
   - **GET `/users/{id}/bonus`** — для получения текущего бонусного уровня пользователя.
   - **POST `/users/{id}/transactions`** — для добавления транзакции пользователя.

2. Убедитесь, что данные о пользователях и транзакциях сохраняются в базе данных.

#### 6. **Остановка контейнеров**

Когда работа с приложением завершена, можно остановить все контейнеры командой:

```sh
docker-compose down
```

- Эта команда остановит все контейнеры и удалит их, но сохранит данные в volumes, если они были настроены.

---

### Примечания:
- **Docker Compose** позволяет удобно управлять несколькими контейнерами одновременно, поэтому важно убедиться, что все сервисы настроены правильно (например, соединение с базой данных через правильный URI).
- **Flask-Migrate** с **Alembic** автоматизирует процесс создания и применения миграций, что помогает поддерживать схему базы данных в актуальном состоянии.
- После каждого обновления моделей (например, добавления новых таблиц или изменения структуры существующих) не забывайте запускать команды миграции.
