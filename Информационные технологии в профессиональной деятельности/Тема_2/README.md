## Исходники и проверка

Рядом с этим файлом сохранены Markdown-версии всех пяти работ. `build_pdfs.py` формирует PDF и обновляет Markdown из единого набора текстов. Для запуска нужны Python, ReportLab и системные шрифты Arial на macOS.

Все PDF имеют формат A4, книжную ориентацию, встроенные шрифты, нумерацию страниц и кликабельные ссылки. Выполнена проверка извлечённого текста на запрещённые тире и стрелки, а также визуальная проверка страниц и таблиц.
