Задание 2.2. для самостоятельной работы «Экспертиза инновационных продуктов».
Для выполнения задания Вам предстоит выступить в роли эксперта инновационных продуктов. Выберите для экспертизы один из инновационных продуктов, который был представлен на Конкурсе инновационных продуктов СПб, возможно, в  рамках рассматриваемой Вами инновационной деятельности при выполнении предыдущих заданий инновационный продукт был представлен на данный конкурс, тогда можете взять его за основу выполнения задания. Представление инновационного продукта на Конкурсе инновационных продуктов СПб это условие важно для экспертизы, т.к. вам будет предложен оценочный бланк, действительный к конкурсной документации последних лет по данному конкурсу (2017-2020 г.г.). Для поиска воспользуйтесь ссылками:

Ресурс городского Конкурса инновационных продуктов: https://petersburgedu.ru/content/view/category/675/ - Портал Петербургское образование, конкурс инновационных продуктов «Петербургская школа 2020»;
Сборники по итогам конкурса инновационных продуктов
https://petersburgedu.ru/content/view/category/635/  (по итогам конкурса 2017 года)
https://petersburgedu.ru/content/view/category/654/  (по итогам конкурса 2018 года)
https://petersburgedu.ru/content/view/category/674/  (по итогам конкурса 2019 года)

Проведите экспертизу инновационного продукта, используя предложенный оценочный бланк (смотреть файл «Экспертный бланк оценки инновационного продукта»). Заполните оценочный бланк, учитывая информацию из сносок в документе. Обратите внимание, в правом столбце необходимо написать аргументацию к поставленным вами баллам по каждой оцениваемой позиции. Сделайте презентацию по итогам экспертизы, в которой разместите информацию о проекте, в рамках которого продукт разработан; описание продукта с сайта образовательной организации (демоверсия, демонстрация продукта и др.); размести ваше особое мнение как эксперта. 

Оценивание: задание для САМОПРОВЕРКИ, поэтому оценивается самим студентом, при этом предлагаем учитывать следующие критерии оценки:
- полнота письменной аргументации к оценочным баллам;
- презентабельность демонстрации инновационного продукта;  
- обстоятельность особого мнения эксперта.
