## Часть 3. Наиболее ценные качества программиста по мнению работодателей

Согласно данным работодателей IT-сферы, наиболее ценными являются:

1. **Умение решать задачи** — способность находить нестандартные решения в условиях ограничений
2. **Аналитический склад ума** — декомпозиция сложных проблем, логическое мышление
3. **Упорство** — доведение задачи до конца несмотря на препятствия
4. **Умение работать в команде** — совместная разработка, code review, взаимопомощь
5. **Хорошая концентрация** — длительная работа с кодом без потери фокуса
6. **Усидчивость** — готовность к монотонной и детализированной работе
7. **Алгоритмизированный подход** — структурированное мышление, разбивка задачи на шаги
8. **Ответственность** — соблюдение договорённостей, дедлайнов, качества кода
9. **Коммуникабельность** — взаимодействие с командой, заказчиком, участие в стендапах
10. **Инициативность** — предложение улучшений, самостоятельный поиск задач

## Часть 5. План «прокачки» качеств с недостаточным весом

### Коммуникабельность (500 гр. → цель: 750 гр.)

**Текущая проблема:** сложность в быстром установлении контакта с незнакомыми людьми в рабочих ситуациях.

**Мероприятия:**
- Активно участвовать в code review — давать и получать обратную связь по коду
- Участвовать в хакатонах и командных учебных проектах для отработки взаимодействия
- Вести профессиональный блог/телеграм-канал — развивает умение доносить мысли
- Посещать IT-митапы для расширения круга профессионального общения
- Практиковать English speaking для коммуникации в международных командах

---

### Инициативность (450 гр. → цель: 700 гр.)

**Текущая проблема:** осторожность при предложении идей в незнакомых или новых контекстах.

**Мероприятия:**
- Систематически читать технические блоги и следить за трендами в стеке (React, Node.js, Python)
- В учебных и личных проектах формулировать и предлагать улучшения даже если никто не просит
- Вести личный лог идей и экспериментов — трекинг предложенных и реализованных инициатив
- Ставить еженедельную цель: предложить хотя бы одно улучшение в учебном или рабочем проекте

---

### Работа в команде (400 гр. → цель: 700 гр.)

**Текущая проблема:** опыт командной разработки ограничен учебными проектами; практика реального git-flow и scrum-процессов недостаточна.

**Мероприятия:**
- Участвовать в open-source проектах на GitHub — реальный опыт работы с чужой кодовой базой
- Освоить Agile/Scrum на практике: пройти курс или стажировку в команде
- Практиковать парное программирование (pair programming) с однокурсниками или коллегами
- Изучить и применять GitFlow, конвенции коммитов, практики code review
- Участвовать в командных хакатонах с незнакомыми участниками

---

### Концентрация / усидчивость (600 гр. → цель: 800 гр.)

**Текущая проблема:** снижение фокуса при многозадачности и длинных сессиях работы.

**Мероприятия:**
- Применять технику Pomodoro (25/5 мин.) для структурирования рабочего времени
- Использовать системы управления задачами (Notion, Trello) для снижения когнитивной нагрузки
- Ограничить отвлекающие факторы во время работы (уведомления, соцсети)
- Практиковать медитацию или осознанные паузы для восстановления концентрации
