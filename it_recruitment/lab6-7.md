## Платформы и инструменты рекрутеров для поиска IT-специалистов

## Аннотированный список 7 популярных инструментов

---

### 1. HeadHunter (hh.ru)

**Тип:** Работный сайт (job board)  
**Стоимость:** Платный (доступ к базе резюме — от ~3 000 руб./мес.; размещение вакансий — от ~3 500 руб. за публикацию)

**Описание:**  
Крупнейшая платформа по поиску работы и сотрудников в России и СНГ. Содержит десятки миллионов резюме, в том числе значительную долю IT-специалистов. Рекрутер может самостоятельно искать кандидатов через базу резюме или ждать откликов на опубликованную вакансию.

| Достоинства | Недостатки |
|---|---|
| Крупнейшая база резюме в Рунете | Высокая стоимость для малого бизнеса |
| Удобные фильтры поиска (стек, зарплата, опыт, регион) | Много нерелевантных кандидатов и спам-откликов |
| Встроенная CRM для работы с откликами | IT-специалисты часто предпочитают другие площадки |
| Аналитика рынка труда (hh.ru/employer/salary) | Пассивные кандидаты редко обновляют резюме |
| Интеграция с внешними ATS-системами | Алгоритм подбора не всегда точен для узких IT-ролей |

---

### 2. LinkedIn

**Тип:** Профессиональная социальная сеть  
**Стоимость:** Условно-бесплатный (базовый поиск бесплатен; LinkedIn Recruiter Lite — от ~10 000 руб./мес.; полный Recruiter — дороже)

**Описание:**  
Крупнейшая в мире профессиональная сеть с более чем 1 млрд пользователей. Используется для прямого поиска (sourcing) пассивных кандидатов, изучения профессионального опыта и выхода на международный рынок. Несмотря на ограниченный доступ из России, многие IT-специалисты сохраняют активные профили.

| Достоинства | Недостатки |
|---|---|
| Крупнейшая мировая база профессионалов | Ограниченный доступ из России (VPN) |
| Детальные профили с реальным опытом и рекомендациями | Дорогостоящая подписка Recruiter |
| InMail — прямые сообщения любому пользователю | Низкий процент ответов на холодные сообщения |
| Поиск по навыкам, должностям, компаниям, вузам | Меньше русскоязычных IT-специалистов, чем на hh.ru |
| Возможность отслеживать смену работы кандидатом | Требует времени на ведение аккаунта рекрутера |

---

### 3. Habr Career (career.habr.com)

**Тип:** IT-специализированный job board  
**Стоимость:** Платный (публикация вакансии — от ~5 000 руб.; доступ к базе резюме — по подписке)

**Описание:**  
Платформа для поиска работы и сотрудников в IT, входящая в экосистему Хабра — крупнейшего русскоязычного IT-сообщества. Аудитория — разработчики, тестировщики, DevOps, аналитики. Кандидаты технически грамотны и хорошо понимают рынок. Вакансии индексируются внутри Хабра, что даёт органический охват.

| Достоинства | Недостатки |
|---|---|
| Аудитория — исключительно IT-специалисты | Меньшая база по сравнению с hh.ru |
| Высокое качество кандидатов | Дороже HH при небольшом объёме найма |
| Интеграция с Хабром: статьи о компании формируют бренд работодателя | Не подходит для найма на нетехнические IT-роли |
| Зарплатный калькулятор и аналитика рынка | Конкуренция за кандидатов среди крупных IT-компаний высока |
| Возможность публиковать корпоративный блог | Кандидаты могут быть требовательнее к условиям |

---

### 4. GitHub

**Тип:** Платформа для хостинга кода и совместной разработки  
**Стоимость:** Бесплатный (поиск по профилям и репозиториям)

**Описание:**  
GitHub — крупнейший хостинг для open-source и коммерческих проектов. Рекрутеры используют его как инструмент sourcing: поиск активных разработчиков по языку программирования, активности в репозиториях, расположению. Позволяет оценить реальный код кандидата до контакта.

| Достоинства | Недостатки |
|---|---|
| Доступ к реальному портфолио кандидата (код, проекты) | Нет системного поиска по кандидатам (нет базы резюме) |
| Поиск по языку программирования и локации | Контактные данные часто не указаны |
| Бесплатный инструмент | Требует технических знаний у рекрутера для оценки профиля |
| Показывает активность разработчика (commit history) | Кандидаты могут не отвечать на нетипичные сообщения |
| Позволяет найти узких специалистов по контрибьюциям в нужные проекты | Только активные open-source участники видны |

### 5. Telegram-каналы и IT-сообщества

**Тип:** Мессенджер / неформальные профессиональные сообщества  
**Стоимость:** Бесплатный

**Описание:**  
Telegram содержит тысячи тематических каналов и чатов для IT-специалистов: по языкам (Python, JavaScript, Go), направлениям (frontend, backend, QA, DevOps) и городам. Рекрутеры размещают объявления о вакансиях напрямую в тематических чатах или договариваются с администраторами каналов на публикацию. Также существуют специализированные каналы только для вакансий.

| Достоинства | Недостатки |
|---|---|
| Полностью бесплатно | Нет инструментов поиска и фильтрации кандидатов |
| Быстрый отклик аудитории | Объявления быстро теряются в потоке сообщений |
| Прямой контакт с кандидатом в мессенджере | Отсутствует верификация кандидатов |
| IT-аудитория, активно ищущая или мониторящая рынок | Нет CRM — всё ведётся вручную |
| Узкотематические чаты позволяют найти редких специалистов | Некоторые каналы требуют оплату за размещение поста |

### 6. SuperJob

**Тип:** Работный сайт (job board)  
**Стоимость:** Платный (размещение вакансий — от ~1 500 руб.; доступ к базе резюме — по подписке, дешевле hh.ru)

**Описание:**  
Вторая по величине работная площадка в России после HH. Широко охватывает все сферы занятости, включая IT. Часть функций доступна бесплатно (базовое размещение вакансии). Привлекает кандидатов из регионов и специалистов уровня junior/middle, ищущих первую или следующую работу.

| Достоинства | Недостатки |
|---|---|
| Ниже стоимость по сравнению с hh.ru | Меньшая база IT-специалистов, чем на hh.ru и Habr Career |
| Охват регионов России | Ниже средний уровень квалификации IT-кандидатов |
| Часть функций доступна бесплатно | Уступает HH по удобству интерфейса и инструментам аналитики |
| Подходит для найма junior-специалистов | Меньше интеграций с ATS-системами |
| Есть раздел для студентов и выпускников | Менее популярен среди опытных IT-профессионалов |

---

### 7. GeekJob (geekjob.ru)

**Тип:** Узкоспециализированный IT job board  
**Стоимость:** Платный (публикация вакансии — от ~2 500 руб.; есть пробный период)

**Описание:**  
GeekJob — российская платформа, ориентированная исключительно на IT-вакансии и разработчиков. Позиционируется как альтернатива Habr Career с упором на технические вакансии: разработчики, QA, DevOps, системные администраторы. Аудитория платформы — активно ищущие специалисты с техническим бэкграундом.

| Достоинства | Недостатки |
|---|---|
| Фокус только на IT — нет нецелевых кандидатов | Небольшая база по сравнению с hh.ru и Habr Career |
| Умеренная стоимость размещения | Меньшая узнаваемость среди кандидатов |
| Удобный интерфейс для работодателя | Охват преимущественно московской и петербургской аудитории |
| Возможность указать технический стек прямо в карточке вакансии | Ограниченные инструменты аналитики |
| Подходит для стартапов и небольших IT-компаний | Меньше трафика, чем у крупных платформ |
