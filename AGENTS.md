# Правила выполнения вузовских работ

Эти требования применяются ко всем учебным работам в этом репозитории, включая PDF, презентации и другие документы.

- Не использовать длинное тире. При необходимости использовать обычный дефис либо переформулировать предложение.
- Не использовать стрелки, включая `->` и символы стрелок. Последовательность действий оформлять нумерованным списком или словами.
- Перед выдачей проверять отсутствие длинных тире и стрелок, а также читаемость вёрстки и таблиц.
- Применять эти требования по умолчанию, если пользователь явно не задаёт другое оформление для конкретной работы.
