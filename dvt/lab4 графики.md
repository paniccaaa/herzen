| :------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Свечной график (Candlestick Chart)** | Визуализация финансовых данных (цены акций, криптовалют) за определенный период. Используется в торговых платформах, инструментах финансового анализа.                       | Отображает цены открытия, максимума, минимума и закрытия за период. "Тело" свечи показывает диапазон между открытием и закрытием, "тени" или "фитили" - максимум и минимум. Цвет тела указывает на рост или падение цены за период. | Применим прежде всего для финансовых временных рядов. Эффективен для выявления трендов, волатильности и стандартных торговых паттернов.                                                      |
| **График плотности (Density Plot)** | Отображение формы распределения непрерывной переменной (например, времени отклика, размера файла, возраста пользователей). Сравнение распределений разных групп данных.            | Сглаженная версия гистограммы, построенная с использованием оценки плотности ядра. Показывает форму распределения более плавно, особенно при большом количестве данных. Позволяет легко увидеть пики (моды) распределения.            | Хорошая альтернатива гистограмме для визуализации формы распределения. Особенно полезен для сравнения форм нескольких распределений на одном графике.                                      |
| **График баров (OHLC Chart)** | Визуализация финансовых данных (цены открытия, максимума, минимума, закрытия) за период. Используется в торговых и аналитических системах.                                    | Показывает цены открытия (левая метка), максимума (верхняя точка вертикальной линии), минимума (нижняя точка) и закрытия (правая метка) для каждого временного интервала. Подобен свечному графику, но в другом представлении.    | Используется для анализа финансовых временных рядов. Передает ту же информацию, что и свечной график, но может быть менее интуитивен для быстрого сравнения цен открытия и закрытия.         |
| **Линейный график (Line Chart)** | Отображение трендов данных во времени (нагрузка на сервер, активность пользователей, показатели производительности). Сравнение динамики нескольких метрик.                           | Соединяет точки данных линиями. Ось X обычно временная или упорядоченная. Показывает изменение и направление тренда.                                                                                                          | Идеален для временных рядов. Убедитесь в корректном порядке по оси X. Избегайте перегрузки слишком большим количеством линий.                                                              |
| **График Каги (Kagi Chart)** | Технический анализ финансовых рынков. Отслеживание движения цен с фильтрацией незначительных колебаний. Используется в специализированном финансовом ПО.                           | Состоит из вертикальных линий ("баров"), которые меняют направление только при превышении ценой определенного порога. Горизонтальные линии показывают точки разворота. Не зависит от времени.                               | Нишевый график для технического анализа. Помогает выявлять значимые тренды и развороты, игнорируя мелкий "шум". Требует понимания логики построения.                                      |
| **График «крестики-нолики» (Point and Figure Chart)** | Технический анализ финансовых рынков. Отслеживание движения цен на основе только ценовых изменений, без учета времени и незначительных движений. Используется в финансовом ПО. | Использует столбцы из "X" (рост цены) и "O" (падение цены). Новый столбец создается только при изменении цены на заданную величину и развороте тренда. Время не отображается.                                              | Нишевый график для технического анализа. Фокусируется на волатильности и сильных ценовых движениях. Требует определения размера "клетки" и порога разворота.                               |
| **Скрипичный график (Violin Plot)** | Сравнение формы распределения непрерывной переменной в разрезе категорий (например, распределение времени выполнения тестов по модулям, времени отклика по версиям сервиса).               | Сочетает ящичковую диаграмму с графиком плотности. Показывает медиану и квартили (часто внутри), а также форму распределения данных в каждой категории. Может выявить мультимодальность.                                       | Предоставляет более детальное представление о распределении, чем ящичковая диаграмма. Отлично подходит для сравнения распределений между группами, показывая их форму.                   |
| **Спиральный график (Spiral Plot)** | Визуализация временных рядов с выраженной цикличностью (например, повторяющиеся паттерны нагрузки на сервер в течение суток или недели, сезонность активности пользователей).         | Данные отображаются вдоль спирали, где радиус обычно представляет общее время, а угол - повторяющийся цикл (час, день недели). Значение может быть показано цветом или удаленностью от центра.                                | Полезен для выявления циклических паттернов во временных данных. Может быть сложен для точного считывания значений, но хорош для визуального обнаружения закономерностей.                    |
| **Потоковый график (Streamgraph)** | Отображение изменения долей или объемов различных категорий во времени, с акцентом на их относительный размер и общий "поток" (например, распределение источников трафика со временем). | Вариант стековой диаграммы областей, центрированный относительно горизонтальной оси и имеющий плавные края. Подчеркивает относительный размер категорий и общий поток данных.                                                 | Хорош для демонстрации эволюции состава целого со временем. Визуально привлекателен, но точные значения считывать может быть трудно. Располагайте категории логично.                      |
| **Дуговая диаграмма (Arc Diagram)** | Визуализация связей или взаимоотношений между элементами, расположенными линейно (например, зависимости между функциями в коде, последовательность событий с переходами).       | Элементы размещаются вдоль одной линии, связи отображаются дугами над или под линией. Высота дуги может показывать силу связи или "расстояние".                                                                            | Подходит для сетей с естественным линейным порядком. Может стать сложной для чтения при большом количестве узлов и связей.                                                                  |
| **Диаграмма с областями (Area Chart)** | Отображение трендов во времени, с акцентом на кумулятивное значение или объем (например, общий объем данных за период). Стековая диаграмма областей - для показа вклада частей в целое со временем. | Основана на линейном графике, область под линией заливается. Стековые диаграммы показывают, как разные категории вносят вклад в общее значение.                                                                           | Используйте для показа трендов и объема. Стековые полезны для композиции во времени, но могут быть трудны для восприятия при множестве категорий.                                            |
| **Столбиковая диаграмма (Bar Chart)** | Сравнение значений между дискретными категориями (например, количество пользователей по региону, частота ошибок по типу).                                                 | Использует прямоугольные столбцы, высота пропорциональна значению. Подходит для категориальных данных. Может быть вертикальной или горизонтальной.                                                                               | Отлично подходит для сравнения категорий. Ограничивайте количество столбцов.                                                                                                           |
| **Диаграмма размаха ("ящик с усами") (Box Plot)** | Сводное представление и сравнение распределений числовых данных (медиана, квартили, разброс, выбросы) между группами (например, сравнение времени загрузки по браузерам). | Отображает медиану, 1-й и 3-й квартили (ящик), размах данных (усы) и отдельные выбросы.                                                                                                                                     | Эффективен для быстрого сравнения основных статистик распределений и выявления выбросов в различных группах.                                                                              |
| **Пузырьковая диаграмма (Bubble Chart)** | Отображение взаимосвязи между тремя или четырьмя числовыми переменными (например, время выполнения функции vs количество вызовов, где размер пузырька - потребление памяти). | Вариант диаграммы рассеяния, где размер маркера (пузырька) представляет третье измерение, а цвет - четвертое.                                                                                                                  | Позволяет показать сложные взаимосвязи. Может стать перегруженной при большом количестве пузырьков. Убедитесь в понятном масштабировании размера.                                        |
| **Пулевая диаграмма (Bullet Chart)** | Отображение показателя относительно цели и качественных диапазонов производительности (например, прогресс выполнения задачи относительно плана, текущее покрытие кода vs целевое). | Компактный график, показывающий основной показатель (полоса), целевое значение (метка) и диапазоны производительности (фоновые цвета).                                                                                           | Идеальна для дашбордов, где нужно быстро показать статус метрики относительно цели и контекста (хорошо/плохо/средне).                                                                 |
| **Хордовая диаграмма (Chord Diagram)** | Визуализация взаимосвязей или потоков между элементами системы (например, зависимости между компонентами, потоки трафика между сервисами).                                 | Элементы расположены по кругу, связи между ними отображаются хордами (дугами внутри круга). Ширина хорды часто показывает интенсивность или объем связи.                                                                 | Подходит для показа сложных взаимосвязей между несколькими элементами. Может быть сложна для интерпретации при большом количестве связей.                                                  |
| **Кольцевая диаграмма (Donut Chart)** | Отображение частей целого, аналогично круговой диаграмме (например, распределение типов запросов, процент выполнения этапов).                                               | Круговая диаграмма с отверстием в центре. Пропорции отображаются длиной дуги. В центре можно разместить итоговое значение или метку.                                                                                            | Подобна круговой диаграмме, имеет те же недостатки при сравнении долей. Центральное пространство может быть использовано для текста.                                                     |
| **Гистограмма (Histogram)** | Отображение распределения частоты непрерывной переменной по интервалам (например, распределение времени выполнения запросов, распределение значений метрики).                 | Столбцы показывают частоту попадания значений в определенные диапазоны (бины). Столбцы обычно примыкают друг к другу.                                                                                                     | Используйте для понимания формы распределения данных. Важен правильный выбор размера бинов. Отличается от столбчатой диаграммы (непрерывные данные vs категориальные).                   |
| **Диаграмма Маримекко (Marimekko Chart)** | Одновременное отображение двух категориальных переменных и их пропорций (например, распределение рынка по продуктам и регионам, breakdown пользовательской базы по типу и источнику). | Похожа на 100% стековую столбчатую диаграмму, но ширина столбцов также переменна и пропорциональна значению. Показывает пропорции как внутри сегментов, так и относительный размер самих столбцов.                              | Сложна для чтения, но может быть информативна для показа пропорций по двум измерениям одновременно. Требует внимательного выбора и упорядочивания категорий.                                |
| **Столбиковая диаграмма с группировкой (Grouped Bar Chart)** | Сравнение нескольких рядов данных между категориями (например, производительность разных версий ПО по набору тестов, количество пользователей разных типов по кварталам). | Столбцы группируются по категориям, внутри группы каждый столбец представляет отдельный ряд данных.                                                                                                                           | Эффективна для прямого сравнения значений разных рядов данных в рамках каждой категории. Не перегружайте слишком большим количеством рядов или категорий.                                   |
| **Сетевая диаграмма (Network Diagram)** | Визуализация связей и взаимоотношений между сущностями (например, зависимости библиотек, структура вызовов функций, связи между микросервисами, инфраструктурные компоненты). | Узлы (nodes) представляют сущности, линии/ребра (edges) - связи между ними. Позволяет увидеть структуру и взаимосвязи в сложных системах.                                                                                    | Основной инструмент для анализа структур данных и систем со связями. Выбор алгоритма расположения узлов (layout) критичен для читаемости.                                                  |
| **Диаграмма «роза найтингейл» (Nightingale Rose Chart)** | Отображение частоты или величины по категориям или временным периодам с циклическим характером (например, количество инцидентов по месяцам, активность по часам суток). | Использует полярные координаты. Категории по углу, величина по длине сектора (или радиусу). Все секторы имеют одинаковый угол.                                                                                                  | Визуально привлекательна для цикличных данных, но сравнение длин секторов на разном удалении от центра затруднительно. Стандартная столбчатая диаграмма часто более точна для чтения. |
| **Диаграмма с параллельными координатами (Parallel Coordinates Plot)** | Исследование и визуализация взаимосвязей и паттернов между несколькими числовыми переменными одновременно (например, сравнение характеристик серверов по CPU, RAM, диску, сети).                 | Каждая переменная представлена вертикальной осью. Каждая точка данных - это линия, соединяющая значения этой точки на каждой оси. Позволяет увидеть кластеры, тренды и корреляции между измерениями.                               | Мощный инструмент для многомерных данных. Эффективность возрастает при интерактивности (фильтрация, выделение линий). Может стать нечитаемой при большом количестве данных или осей.       |
| **Диаграмма Санкея (Sankey Diagram)** | Визуализация потоков и перетоков между разными состояниями или сущностями (например, пользовательский путь по приложению, распределение бюджета, потоки данных между компонентами). | Узлы представляют сущности/состояния, стрелки - потоки между ними. Ширина стрелки пропорциональна объему потока. Наглядно показывает, как количество разделяется, объединяется и движется по системе.                             | Отлично подходит для демонстрации процессов с потоками. Помогает выявить основные пути и узкие места. Требует аккуратного расположения узлов и понятных подписей.                        |
| **Древовидная диаграмма (Tree Diagram)** | Визуализация иерархических структур (например, структура файловой системы, вызовы функций, наследование классов, структура проекта).                                   | Использует узлы и ветви для отображения связей "родитель-потомок". Может быть ориентирована вертикально или горизонтально.                                                                                                  | Четко показывает иерархию. Читаемость ограничена при очень глубоких или широких структурах.                                                                                              |
| **Древовидная карта (Treemap)** | Визуализация иерархических данных, где размер прямоугольника пропорционален значению (например, использование дискового пространства по папкам, вклад модулей в общий размер кода). | Использует вложенные прямоугольники. Площадь каждого прямоугольника соответствует его значению. Цвет может показывать дополнительную метрику. Эффективно использует пространство.                                             | Хорошо подходит для отображения иерархии и относительных размеров элементов в ней. Эффективна для показа "части целого" в иерархическом контексте. Названия мелких элементов могут быть нечитаемы. |
| **Облако слов (Word Cloud)** | Визуализация частоты слов в текстовых данных (например, часто используемые термины в логах ошибок, популярные запросы пользователей, ключевые слова из документации).                | Размер слова пропорционален его частоте встречаемости. Может использовать цвет для группировки или дополнительных метрик.                                                                                                 | Позволяет быстро получить общее представление о наиболее часто встречающихся терминах. Не подходит для точного анализа частоты. Требует предварительной обработки текста.                 |
| **Пузырьковая карта (Bubble Map)** | Визуализация данных, связанных с географическим расположением, где размер или цвет пузырьков на карте показывают значение (например, количество пользователей по городам).    | Накладывает пузырьки на географическую карту. Размер пузырька пропорционален значению метрики в этой локации.                                                                                                                | Хорошо подходит для визуализации распределения количественной метрики по географическим областям. Избегайте перекрытия пузырьков при большой плотности данных.                              |
| **Календарь (Calendar Heatmap)** | Визуализация данных по дням в формате календаря, где цвет ячейки дня показывает значение метрики (например, количество коммитов в репозиторий по дням, интенсивность использования функции). | Представляет данные в виде календаря (по месяцам, неделям). Цвет каждого дня в ячейке календаря соответствует значению определенной метрики.                                                                               | Отлично подходит для выявления ежедневных или еженедельных/ежемесячных паттернов и аномалий во временных рядах.                                                                        |
| **Точечная карта (Dot Map)** | Визуализация географического распределения отдельных объектов или событий (например, расположение серверов в дата-центрах, места возникновения ошибок на карте).             | Наносит каждую точку данных на географическую карту.                                                                                                                                                                         | Показывает плотность и распределение объектов.
