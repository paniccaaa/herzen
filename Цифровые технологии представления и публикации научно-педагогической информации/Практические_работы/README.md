- `01_Стендовый_доклад.pdf`: копия ранее созданного стенда о Tsunami. Исходный файл в репозитории сохранён без изменений. В Moodle он уже отправлен для оценивания.
- `01_Комментарий_к_стенду.pdf`: отдельный комментарий о сложностях, удобстве формата и соотношении с устным выступлением.

## Практическая работа 2

- `02_Инфографика_Go.pdf` и `.png`: авторская схема обучения конкурентному программированию на Go. Содержит подпись автора и источники.

## Практическое задание 3

- `03a_Анализ_редакторов_LaTeX.pdf`: Overleaf, Papeeria, CoCalc, TeXPage, SwiftLaTeX; возможности, ограничения, выбор.
- `03b_Памятка_LaTeX.pdf`: команды, окружения и типичные ошибки.
- `03c_Фрагмент_ВКР_LaTeX.pdf`: двухстраничный проект фрагмента ВКР по текущей теме, с рисунком, таблицей, формулой и ссылками. Это проект текста, а не выданный за существующий фрагмент или отчёт об эксперименте.
- `03c_main.tex`: точный исходник, скомпилированный в гостевой песочнице Papeeria с XeLaTeX. Журнал финальной сборки не показал ошибок. Используются CMU Serif и CMU Typewriter Text. Рисунок создан средствами LaTeX, внешние изображения не нужны.

## Практическое задание 4

- `04_Интерактивный_дашборд.html`: самостоятельный HTML-файл, открыть в Safari или Chrome двойным щелчком. Фильтры года и направления, поиск, сортировка, выбор года столбцом, сброс и ссылки DOI.
- `04_Статьи.csv` и `.json`: десять записей из задания 1 по Smart-обучению. Это реальный состав авторской подборки, а не статистика всей научной области.
- `04_Datawrapper_скриншот.jpg`: снимок диаграммы, созданной в Datawrapper, с заголовком, источником и ограничениями.
- `04_Дашборд_скриншот.jpg`: снимок автономного дашборда.
- `04_Отчёт_по_дашборду.pdf`: данные, метод, инструкция, ограничения и снимок Datawrapper.

Datawrapper позволяет построить диаграмму в гостевом режиме, но требует входа для публикации и штатного экспорта. Публичная публикация не выполнена. В комплекте сохранён снимок, а интерактивность обеспечена автономным HTML, который работает без сервера и внешних библиотек. Интернет требуется только для открытия DOI. Временный гостевой предпросмотр: https://app.datawrapper.de/preview/9p14j?previewId=publish . Он не заменяет постоянную копию.
